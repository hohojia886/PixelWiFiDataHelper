# Pixel WiFi & Data Helper
**Version:** v1.0.0

A professional LSPosed module designed for Android 17 (V) to restore intuitive and efficient Quick Settings behaviors that were altered in the latest OS versions.

## 🚀 Features

- **True WiFi Toggle**: In Android 17, the default behavior for the WiFi Quick Setting tile is just "pause" the WiFi connection. This module hooks into the system to restore the traditional behavior: clicking the toggle now physically turns the WiFi chip **ON** or **OFF**.
- **Mobile Data Bypass**: Removes the redundant "Turn on mobile data?" confirmation dialog when enabling cellular data from the Quick Settings. Data will now enable instantly with a single tap.

## 🛠 Requirements

- **Device**: Pixel running Android 17.
- **Environment**: LSPosed Framework (API 102 compatible).
- **Target**: SystemUI (`com.android.systemui`).

## 📥 Installation

1. Download and install the latest [release APK](app/build/outputs/apk/debug/app-debug.apk).
2. Open the **LSPosed Manager**.
3. Enable the **Pixel WiFi & Data Helper** module.
4. Ensure **SystemUI** is selected in the scope (pre-configured).
5. Reboot SystemUI or restart your device to apply changes.
