# Pixel WiFi & Data Helper
**Version:** v1.0.2

A professional LSPosed module designed for Android 17 or higher to restore intuitive and efficient Quick Settings behaviors that were altered in the latest OS versions.

## 🚀 Features

- **True WiFi Toggle**: In Android 17, the default behavior for the WiFi Quick Setting tile is often to just "disconnect" or "pause" the connection. This module hooks into the system to restore the traditional behavior: clicking the toggle now physically turns the WiFi chip **ON** or **OFF**.
- **Mobile Data Bypass**: Removes the redundant "Turn on mobile data?" confirmation dialog when enabling cellular data from the Quick Settings. Data will now enable instantly with a single tap.
- **Material 3 Interface**: A modern, clean settings interface built with Material Design 3, featuring Edge-to-Edge support and a dynamic user experience consistent with the latest Android design language.
- **Optimized Build**: Fully compatible with R8/ProGuard for a minimal memory footprint and small APK size.

## 🛠 Requirements

- **Device**: Android device running Android 17 or higher.
- **Environment**: LSPosed Framework (API 102 compatible).
- **Target**: SystemUI (`com.android.systemui`).

## 📥 Installation

1. Download the latest release from the [GitHub Releases](https://github.com/hohojia886/PixelWiFiDataHelper/releases) page.
   - APK name format: `pixel-wifi-data-helper-v1.0.2-release.apk`
2. Install the APK on your device.
3. Open the **LSPosed Manager**.
4. Enable the **Pixel WiFi & Data Helper** module.
5. Ensure **SystemUI** is selected in the scope (pre-configured).
6. Reboot SystemUI or restart your device to apply changes.
